# Day 19 — PyTorch CUDA subset run

This directory preserves the lightweight outputs from the verified Day 19
training run. Large model and optimizer checkpoints remain under
`checkpoints/day19/torch/` and are intentionally ignored by Git.

## Run configuration

- Device: NVIDIA CUDA (Quadro M2000M)
- Dataset: first 2,000 aligned Multi30k training pairs and first 200 validation pairs
- Tokenizer: joint English/German BPE, 512 tokens, trained only on the selected training pairs
- Model: 64-dimensional, 4 heads, 2 encoder and decoder layers, 256-dimensional FFN
- Batch size: 64
- Epochs: 4 (epoch 4 resumed from the epoch-3 `latest.pt` checkpoint)
- Optimizer steps: 128

## Results

| Epoch | Train loss | Validation loss | Train tokens/s |
|---:|---:|---:|---:|
| 1 | 5.6325 | 5.3585 | 11,896 |
| 2 | 5.2564 | 5.1375 | 13,331 |
| 3 | 4.9751 | 4.9695 | 13,267 |
| 4 | 4.8897 | 4.9280 | 11,397 |

Both loss series decreased and remained finite. The short run is an execution
and learning sanity check, not a translation-quality claim: the qualitative
samples are still repetitive, as expected after only 128 updates. Longer
training is deliberately left for Day 20 and formal BLEU evaluation for Day 23.

Artifacts:

- `history.jsonl` — exact per-epoch metrics.
- `translations.jsonl` — source, reference, and prediction samples by epoch.
- `loss_curve.svg` — train/validation loss curve generated by the training CLI.
